# EduEvent

University event platform — hackathons, AI-proctored quizzes, live leaderboards,
and verifiable certificates. Spring Boot + MongoDB Atlas, served as a single app.

Set these as **Space secrets** (Settings → Variables and secrets):
`MONGODB_URI`, `JWT_SECRET`, `MAIL_USERNAME`, `MAIL_PASSWORD`.
